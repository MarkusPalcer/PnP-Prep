
Die Klasse \texttt{pnpprep} erweitert die Standardklasse \texttt{report} um eine Reihe von Befehlen und Umgebungen, die speziell zum Schreiben von Pen\&Paper-Abenteuern entwickelt wurden.

Neben einem angepassten Seitenlayout stellt sie unter anderem folgende Funktionen bereit:

\begin{itemize}
\item Hervorgehobene Hinweise für den Spielleiter
\item Dialogdarstellung
\item Musikhinweise
\item Entscheidungsblöcke
\item Sammelproben
\item Gegnerwertekästen
\item Allgemeine Boxen mit frei wählbaren Farben
\end{itemize}

\subsection{Allgemeine Eigenschaften}

Beim Laden der Klasse werden automatisch einige Einstellungen vorgenommen.

\begin{itemize}
\item Papierformat A4
\item Seitenränder von 2\,cm
\item Keine Seitenzahlen
\item Keine Absatzeinzüge
\item Vertikaler Abstand zwischen Absätzen
\item Deutsche Sprachunterstützung
\end{itemize}
